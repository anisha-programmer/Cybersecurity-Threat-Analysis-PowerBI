# 🌐 Global Cybersecurity Threat Analysis Dashboard

An interactive Power BI dashboard designed to analyze **3,000+ global cybersecurity incidents from 2015–2024** and identify trends across industries, countries, attack sources, security vulnerabilities, financial losses, affected users, defense mechanisms, and incident resolution time.

This project demonstrates practical skills in **Data Analysis, Data Cleaning, Power Query, DAX, KPI Development, Data Visualization, and Business Intelligence reporting**.

---

## 📊 Project Overview

Cybersecurity incidents can have significant financial, operational, and user-related impacts across different industries and countries.

This project transforms raw cybersecurity incident data into an interactive Power BI dashboard that provides a consolidated view of cybersecurity threats and their impact.

The dashboard allows users to explore cybersecurity data through interactive filters, KPI cards, charts, and analytical visualizations.

---

## 🎯 Project Objectives

- Analyze global cybersecurity incidents from **2015 to 2024**
- Identify cybersecurity attack trends over time
- Analyze financial losses caused by cyber incidents
- Examine the number of affected users
- Compare incidents across different industries
- Analyze attack sources and security vulnerabilities
- Examine defense mechanisms used against cyber threats
- Analyze incident resolution time
- Develop interactive KPIs and analytical reports
- Generate data-driven insights for cybersecurity monitoring

## 🗂️ Dataset

### Dataset Name

`Global_Cybersecurity_Threats_2015-2024`

### Dataset Details

- **Records:** 3,000+
- **Time Period:** 2015–2024
- **Format:** Excel (.xlsx)
- **Domain:** Cybersecurity Analytics

### Dataset Columns

| Column | Description |
|---|---|
| Country | Country where the cybersecurity incident occurred |
| Year | Year of the incident |
| Attack ID | Unique identifier for each incident |
| Target Industry | Industry targeted by the attack |
| Financial Loss | Financial loss caused by the incident |
| Number of Affected Users | Number of users affected by the incident |
| Attack Source | Source or category of the attack |
| Security Vulnerability Type | Vulnerability associated with the incident |
| Defense Mechanism Used | Defense mechanism used against the threat |
| Incident Resolution Time | Time required to resolve the incident |
